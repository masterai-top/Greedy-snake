## 🧠 Project Overview


This is an implementation of a classic Snake arcade game.


Players control the snake, eat food, and grow longer without colliding.



---


## 🎮 Gameplay


- Grid-based movement
- Eat food to grow
- Avoid collisions
- Score tracking
